# AI-Based Student Performance and Dropout Prediction System

## Institution
Sharda University

## Department
Electronic and Computer Engineering (ENC)

## Project Description

This project uses machine learning to analyse student
academic information, predict academic performance,
and identify potential dropout risks.

## Project Objectives

1. Predict student academic performance.
2. Identify potential dropout risks.
3. Analyse student academic information.
4. Generate academic recommendations.

## Technologies Used

- Python
- Streamlit
- Pandas
- NumPy
- Scikit-learn
- Random Forest Classifier
- Random Forest Regressor
- SQLite
- Joblib

## Application Modules

1. Dashboard
2. Student Registration
3. Student Records
4. Student Prediction
5. Prediction History
6. About Project

## Installation

Install dependencies:

pip install -r requirements.txt

Run the application:

streamlit run app.py

## Disclaimer

Predictions are estimates intended to support academic
monitoring. They should not replace verified academic
records or human review.
